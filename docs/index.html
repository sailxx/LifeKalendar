«Авто» — тёмная или светлая по теме системы. Картинка — на сегодня; чтобы обои обновлялись сами, ниже программа для Windows и скрипт для macOS и Linux.

Windows: программа

Всё как на телефоне: темы, смена вместе с Windows или по времени, размер, место, рабочий стол и экран блокировки, все мониторы сразу. Нажми «Поставить обои» — программа уйдёт в трей и будет запускаться вместе с Windows. Обои обновляются, пока она в трее; закрыть совсем — «Выход» в меню значка. Без прав администратора.
